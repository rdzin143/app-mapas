# Mapas de Anatomia Palpatória

Biblioteca das 120 fichas de anatomia palpatória dos membros superiores, com busca, filtros por região e plano, favoritos, progresso de estudo e texto transcrito de cada ficha.

Site estático, sem build: basta publicar esta pasta na Vercel (Framework Preset: Other).

- `index.html`: o app
- `cards/`: miniaturas das fichas
- `hd/`: fichas em alta resolução (usadas no zoom)
- `vercel.json`: cache das imagens
